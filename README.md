# 🌿 Leaf Disease Prediction App

A deep learning-based Android application that identifies diseases in plant leaves using image classification. This tool helps farmers and researchers detect plant diseases early and take preventive actions.

---

## 🚀 Features

- 📷 Capture or upload images of leaves
- 🤖 Predicts the disease using a trained CNN model
- 💬 Shows the predicted disease name with basic guidance
- 📱 Runs directly on Android devices using TensorFlow Lite
- 🌾 Useful for farmers, students, and agriculture researchers

---

## 🧠 Model Overview

- **Architecture**: Convolutional Neural Network (CNN)
- **Framework**: TensorFlow / Keras
- **Deployment**: Converted to `.tflite` and integrated into Android app
- **Input**: Leaf image (resized, normalized)
- **Output**: Predicted disease label


---

## 📱 Android App

- Developed using Android Studio
- Users can capture or upload leaf images
- Predictions are made on-device using the TFLite model
- Simple and clean user interface
